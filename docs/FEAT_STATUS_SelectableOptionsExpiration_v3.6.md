**Current Status:** `PLANNED`
**Last Updated:** 2025-08-15

**Summary:** This feature is currently in the planning stage. The objective is to build a new, user-driven workflow for selecting specific options expiration dates. To ensure application stability, this entire feature will be developed in a new, completely isolated "Staging: Options" tab. All UI controls, state management, and server actions for this feature will be self-contained and will not interact with the main analysis pipeline.
